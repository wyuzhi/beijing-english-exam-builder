# 质检与交付

## 必做内容检查

1. **范围与模式**：教材身份与依据是否真实；每个核心考点在用户范围内；拓展词/结构是否有说明。按 [初高中模式](school-stage-modes.md) 检查：初中定制卷仅默认语法单选、1篇完形、4篇阅读、1篇作文，无自动混入的语篇填空、阅读表达或句子表达；高中年级和考试目标已明确，其他模块有对应北京样本依据。未知项目不能被“已匹配”总标签覆盖。
2. **独立作答**：临时忽略拟定答案，完整做一遍学生卷。检查所有选项与允许的填空变体。原题标准答案有误时说明原因，不迁移错误。
3. **证据**：阅读题有可定位证据；推断没有跳到外部常识；事实性知识有可信依据，或明确为教学虚构。虚构故事不能伪称真实新闻/调查。
4. **完整性**：材料、图、空格、题号、选项、答案一一对应，跨题无泄露；完形回填后通顺，写作范文符合提示。
5. **递进**：各版本核心目标一致；教师表解释至少一个实质变化；挑战层仍符合已教范围。平行卷则检查负荷相当。
6. **交付**：学生卷无答案与解析；教师卷与最终学生卷版本对应；分值相加正确，声明的词数/题量实际核对。排版不把题干和全部选项分到不同页，不出现不可读小字和被裁切表格。

单选题要求唯一最佳答案。“有两个也说得通”不是可忽略的小问题，应改题；开放题则明示评分点和合理变体，不机械追求唯一字符串。答案字母不刻意排成整齐规律，也不为了平均分布牺牲题质。

对难度递增、教材对齐和原创程度只报告已做的检查，未做学生试测不要声称测评效度已获验证。参考学科网VIP/精品时，核对平台标签与实际已读页码/题号分别记录；题目质量仍由答案唯一性、证据、干扰项及适配检查支持，不能以VIP名号自我认证。

## 教师卷的最小解释粒度

| 题型 | 至少提供 |
|---|---|
| 阅读选择 | 答案＋定位/短证据＋解题依据＋各干扰项错误原因 |
| 阅读表达 | 信息点、参考表达、等义可接受边界、分值拆分（有分值时） |
| 完形 | 每空答案、上下文依据、其他选项不成立的原因；完整回填文 |
| 语法单选 | 唯一最佳答案、关键语境/规则、每个干扰项错因 |
| 语法填空/词汇 | 答案及变体、关键语境/规则、常见错误 |
| 写作/口语 | 分项量规、参考范例、任务覆盖情况、常见扣分点 |

## 文件与排版

短练习在对话中将学生版放前、教师版放后。完整文件交付优先可编辑DOCX两份，用户要PDF时再导出并检查；无文档工具时可交付Markdown两份并说明。创建Word/PDF应使用当前环境的文档处理能力，需要时读取对应技能。不要把答案写进学生文件的隐藏文字、批注或文档属性。

建议文件名：`八年级_一般过去时_阅读分层_学生版.docx`、`八年级_一般过去时_阅读分层_教师版.docx`。精确同步未核实时文件名用考点而非捏造单元标题。输出当前项目目录，不把课程成品塞入技能安装目录；提供真实绝对路径和文件夹入口，不默认压缩。

整套交付后附简短说明：

- 本次学段模式、实际题型/题数/分层数量；学生卷、教师卷和分值汇总保持一致。
- 教材匹配依据与未核对项。
- 设计难度递进理由；未经实测时如实标注。
- 若参考VIP/精品，列实际可见标签、已读范围与未核验模块；普通预览不得写成完整会员卷已读。
- 如有实际发现的待处理问题，指出受影响题目；能修复的先修复，不能把明显缺陷留给教师。

## 题库记录（仅需积累或导出时）

保留学生内容与教师内容两个字段区，导出学生卷只读取学生区，教师区不可混入。推荐JSON结构，不强制用户手填：

```json
{
  "id": "R01-L2",
  "parent_source_id": "SRC01",
  "grade": "初二",
  "textbook_key": "待核对",
  "alignment_status": "通用训练",
  "scope_evidence": ["用户指定：一般过去时"],
  "task_type": "reading",
  "level": "L2",
  "targets": ["从人物行为推断品质"],
  "student": {
    "passage": "此处存实际完整语篇",
    "items": []
  },
  "teacher": {
    "answers": [],
    "level_rationale": "此处记录实际递进设计",
    "source_note": "教学虚构原创语篇"
  },
  "validation": {
    "content_reviewed": false,
    "student_trialed": false
  }
}
```

示例仅说明字段，不是合格题目；实际题目必须填完整。每小题再保存唯一题号、题干、选项、答案、可接受变体、解析、证据、分值（如有）。自由文本字段可能含换行/逗号，CSV导出须正确转义。批量制作保持原题到变式的关系，文本改动后同步修订答案和记录版本。
