# 北京样卷风格与组卷蓝图

## 用户已确定的组卷偏好

先按 [初高中模式与防混入规则](school-stage-modes.md) 选择学段及考试目标，再保留三项数量：分层版本数、每套阅读篇数、每篇小题数。

| 参数 | 默认教学配置 |
|---|---|
| 分层版本 | 要分层时4套，用户指定3套则3套 |
| 每套阅读 | 4篇，标A/B/C/D |
| 每篇阅读小题 | 4题，可按要求改为3题 |
| 初中其他必含模块 | 语法单项选择、1篇完形填空、1篇作文；与四篇阅读组成完整默认卷，不自动加其他题型 |
| 初中未指定题量 | 语法单选10题、完形10空、作文1题；分值按教学配置，不冒充官方考试配置 |
| 高中核心模块 | 完形、语法填空、四篇阅读、作文；先确定具体年级及校考/北京高考目标，题量和其他模块按对应北京实际样本独立配置 |
| 初中阅读体裁 | 以记叙、说明为主，默认A/B记叙、C/D说明；依年级与样卷可加入信息类应用文 |
| 高中阅读体裁 | A/B优先记叙，C说明，D说明或议论；用户定制教学配置，不能称为所有北京试卷统一规则 |

“四道阅读完形”在这个项目中按“四篇阅读，另有完形”处理，蓝图写出单位便于用户纠正。单项任务只做所需题型，不因这些综合卷默认而扩写整卷。

A—D是同卷不同篇章，L1—L4是不同训练版本。建议内部标识为 `SET-L2-RC-Q3`，表示第二难度套卷的C篇第3题。全卷四版保持各篇体裁与核心技能可比，再逐步增加证据整合与推断要求。

## 学科网风格须从样卷提取

“学科网”是资料平台，不是一个统一命题人。仿照的是平台上**北京、目标年级、目标学期、相近考试场景**的具体试卷。不能拿外省高考、初三模拟题直接定标初一，也不能以资源上传者在北京推定试卷为北京卷。

按用户要求主动检索可合法访问的材料，优先同年级近1～2个学年的北京期中/期末/模拟样卷及可见的VIP/精品资源。用户已有且可合法访问的试卷优先。尽量比较2～3份同类样卷；只有1份时注明依据有限，不将凑数量当作完成条件。VIP/精品只能记录为实际看到的平台标签，不能据此认定题目无误或宣称本卷达到“VIP认证质量”。

可用检索式（按实际年级、学期替换）：

- `site:zxxk.com 北京 八年级 英语 上学期 期末`
- `site:zujuan.xkw.com 北京 高一 英语 阅读理解`
- `site:zxxk.com 北京 高二 英语 2025-2026 期末`

通过正常页面访问、浏览器预览或用户提供文件读取。只看到标题/标签/搜索摘要只能确认该资源存在，不能称为读过题干。遇到登录、会员或付费限制，不绕过也不自行购买；说明可见范围，并用用户材料或清楚标注的教学配置继续制作。不要无休止重复失效搜索，也不要静默把其他平台当作学科网来源。

## 提炼“风格卡”

读取实际题干后按需使用 `assets/paper-style-profile.yaml`。记录可观察项：

1. 样卷标题、URL或本地位置、试卷年份、年级/学期/区、访问日期、实际可见的VIP/精品标签、已读页码/题号及未读范围；分别记录平台标签与读取状态。
2. 模块顺序、篇数、小题数、分值和时长（仅已见到时）。
3. 各阅读篇实际体裁、主题、结构（如问题—方法—结果、经历—转折—反思）、大致语言负荷。
4. 设问组合：细节、原因、推断、主旨、词义/指代、写作目的等；不要预设四题必须四类齐全。
5. 干扰项机制：对象错配、顺序颠倒、范围扩大、局部正确但答非所问、把建议当事实等。
6. 完形的词义/语篇比重；实际出现的语法单选或语法填空的知识范围；作文任务的受众、目的、信息约束与支架。

任何比例、篇幅区间、词数均来自实际可见样本并说明统计口径，否则写定性观察。样卷自带难度标签只能记为平台标签，不等同本班正确率。

## 相似风格与难度如何落实

模仿题型组合、文章组织、证据跨度、选项干扰方式和语域；新建主题细节、材料与题目，不复制整篇商业题，也不只做表面替换。

匹配优先级为：用户明确要求及教材边界→目标考试准确结构（仅考试仿真）→所选同年级样卷特征→教学默认。若用户偏好A/B记叙而样卷A为应用文，课堂定制按用户偏好；真实考试仿真按样卷，并解释体裁差异。

年级难度从该年级已学语言与真实样卷推定，不直接用“初中”“高中”两档统一处理。初一可较多显性支架；高一不能直接套高三的抽象论证强度。这些是设计方向，具体仍由班级水平与证据决定。

同一版中A—D可逐步提高信息处理要求；跨版L1—L4也递进，但L4不得自动超出该年级和教材范围。教师卷附一张对照表：`样卷观察｜本卷采用方式｜保留/调整原因｜依据是否已核验`，用真实题干的证据跨度、选项干扰和答案质量说明借鉴方式，不以VIP名号自我认证。没有实际样卷时写“按用户教学配置制作，学科网样卷难度尚未校准”，不声称已经等难度。

## 教学综合卷与考试仿真

初中用户定制卷只默认语法单选、1篇完形、4篇阅读和1篇作文；不自动加入语篇语法填空、阅读表达或句子表达。这不表示北京所有初中官方试卷没有这些题型，历史样卷记录应保留。高中使用独立北京模式，不沿用初中模块或全国卷结构。用户明确要某年区统考/校考/中高考仿真时，按对应真实样卷还原实际模块，不能为了覆盖能力库加题；只有用户另行明确要求拓展时，才单列附加练习。

当前核验到的外部来源和可见范围见 [官方与平台资料](official-sources.md)；旧样卷仅作历史风格参考，下次任务重新核对时效性。

## 可复用的初步观察

已读学科网北京高一期末分类汇编公开预览：记叙文并不只考事件细节，也可从人物决定/后果推断品质或提炼启示；说明文可考例子作用、机制解释、观点态度与写作目的。生成时让材料结构自然支持这些问题，答案依靠文本证据收敛。相应URL、原题年份与预览限制见上述资料表。这些是有限样例的定性参考，不是所有年级的固定题型配比。

已读八年级北京密云期末记叙文首篇的3问，呈现直接细节→人物行为原因→篇章启示；可用于同年级熟悉生活情境的题组设计。七年级朝阳期末公开预览的A篇为信息匹配，提醒仿真时保留真实任务类型，不能把用户的体裁偏好误当北京所有年级固定格式。
