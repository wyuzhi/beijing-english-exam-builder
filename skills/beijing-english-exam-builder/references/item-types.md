# 题型设计与常见失效

按当前题型阅读相应段落。以下是能力库，并非默认组卷清单或北京任一年份官方题型清单；模块选择服从 [初高中模式](school-stage-modes.md)。初中定制卷不默认阅读表达、语篇语法填空或句子表达。

## 阅读理解与阅读表达

每篇完整给出标题（若有）、正文和独立小题。默认4题可覆盖细节、推断、主旨、语境词义/指代，但由文章能支持的考点决定；不为了凑四类强行出无依据题。

- 细节题：题干限制对象/时间，正确选项不超出原文，避免单凭词面复现选答案。
- 推断题：答案必须从已给证据推出，不能把“可能发生”当成“文中可推断”。错误选项即便现实中合理，也应在文中无足够支持或与文本冲突。
- 主旨/标题：范围涵盖全文中心，排除过大、过小或偏离论证的标题；不能两个概括同样成立。
- 词义/指代：文中必须出现目标词或短语，明确所在句/段；靠语境有可达答案，不能纯考罕见词典义。
- 阅读表达（仅采用该题型时）：写清字数/信息点要求；给参考答案、必需信息点、等义表达及分步给分，不要求逐字照抄唯一句子。
- 同一篇中各题不能相互泄露答案。读前说明、标题和注释也要检查是否泄题。

教师解析至少含：答案、证据位置及必要的短证据、中文说明、每个干扰项错因。不要输出不必要的长原文翻译，用户要求精读时再加。

## 完形填空

先写逻辑连贯的完整文章，再按考点挖空并设选项；保留开头必要的情境信息，避免连续挖空使语篇无法建立。控制空位距离，题量由用户要求或样卷确定。

检查全文回填后的语法、搭配、指代、时间线和因果。每个空确认所需证据在合理距离内，不能一个空的未知答案决定另一空且无独立线索。词性或形态不能无意泄题（除非这就是目标）。同词性选项需有语境上的可辨区别。

逐空解析标注句内搭配、局部语义、篇章衔接或主题判断；若两个候选都自然，改上下文或选项后重新回填。教师卷保留完整回填短文便于核验。

## 语法单项选择

这是初中综合卷的默认语法模块。用句子或简短对话给足时态、指代、语义及交际条件，每题只有一个最佳答案；不能把仅在设想情境下成立的“标准答案”强加给信息不足的题干。

- 围绕已教语法设题，选项保持可比，干扰项体现常见错误，不用荒谬选项或冷僻词凑数。
- 时态、情态、冠词、介词、比较结构等均需检查其他选项在现有语境中是否也成立；存在合理多解时改题。
- 教师解析包含答案、决定答案的语境、语法规则和每个干扰项错因。不得将单选模块替换成无选项的独立语篇填空。

## 语法填空与词汇题（按所选模式或明确专项要求）

区分有提示词、无提示词、选词填空；说明每空允许的词数、词形变化规则、选项是否复用。给定约束必须与真实答案兼容，如“每空一词”不可对应 `has been working`。

- 时态/语态：给足时间与语境；没有时间锚点时不能强行只收一种合理时态。
- 冠词/介词/连接词/关系词：检查是否存在多种自然表达；限制性定语从句等若确有多个合规形式，列入可接受答案，或改语境使答案收敛。
- 动词形式/词性转换：词法、句法和句意同时成立；从句边界不应因标点错误造成多解。
- 开放填空：把合理变体列入评分说明；需要自动判分时先明确变体规则，不能伪装唯一答案。
- 选词填空：标明多余项/是否可重复，检查全篇匹配而非只检查单空。

教师解析包括答案（及变体）、语境线索、结构/规则和常见误用。不把“固定搭配”作为所有问题的空泛解释。

## 作文与其他书面表达

给足身份、受众、目的、情境、内容要点和用户指定词数。默认建议词数只能叫“本练习要求”，不冒充中高考规定。

每版提供：任务、写作支架（若该层需要）、评分细则、参考范文及简短讲评。分项分值加总正确；评价至少覆盖任务完成、结构衔接、语言准确与得体表达，按目标和年级分配。范文是可行写法之一，不是唯一标准答案。

逐项检查范文满足所有要点、实际词数在所标范围内、语言水平适合该层。需要报告准确词数时用程序统计并说明连字符/缩写计数方式。读后续写须衔接原文与段首语、不推翻人物设定；概要不添加新论点。这些可作课堂拓展，是否属于目标考试另核验。

## 其他可选题型

| 题型 | 适用练习目标 | 必查点 |
|---|---|---|
| 篇章补全/七选五/段落排序 | 衔接、逻辑与篇章结构 | 每空局部与全文都匹配，干扰句不能同样自然 |
| 信息匹配/任务型阅读/图表阅读 | 获取与整合信息 | 图表实际随题给出；单位、时间、数据一致，不依赖缺失图 |
| 语境单选 | 词汇、交际、语法辨析 | 上下文限制清楚，不靠有争议的语感判唯一 |
| 句型转换/句子合并 | 结构运用 | 转换前后意义一致；提示词、词数限制可实现 |
| 翻译/补全句子 | 情境表达 | 接受合理表达，关键得分点单独列出 |
| 短文改错/纠错 | 发现并修正错误 | 标明每处改动规则，原文确有目标错误，标准变体不算错 |
| 听力脚本＋题目 | 听取细节、意图、笔记 | 明确“脚本，未生成音频”；音频交付须实际生成并检查。默认不给学生卷附听力脚本 |
| 口语问答/情景对话/复述 | 交流、组织与语用 | 给任务、准备/作答要求及评价量规，避免只有一条背诵答案 |
| 看图写话/图表写作 | 观察与信息表达 | 图片/数据必须实际存在且可读；没有图片时改成明确文字情境或请求素材 |

用户要求“越丰富越好”时，在已确定模块内丰富考点与材料，不自动增加题型。初中定制卷仍只有语法单选、完形、四篇阅读和作文；高中新增模块按对应北京实际样本独立配置。题量、学生可承受时间和既定目标优先。
