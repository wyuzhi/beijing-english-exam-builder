# 初高中组卷模式与防混入规则

这是用户的组卷偏好，不是北京所有学校或历年考试的统一题型清单。出版社用于教材对齐，学段和考试目标用于选择组卷模式；不能因外研、北师大、人教之间切换而改变初中默认模块。

## 先选模式

1. 从会话或材料确定具体年级、教材与范围。单篇改编或专项训练只做所需题型，不自动扩成综合卷。
2. 初一至初三的普通综合训练采用下述“初中用户定制模式”。
3. 高中采用独立北京模式：优先从材料提取高一、高二或高三，以及校考/区统考还是北京高考目标，不能把一个年级的样卷替代其他年级。信息缺失且影响真实考试仿真时必须补问；通用示范可补问并给予合理回应时间后，明确采用的年级与教学假设继续制作，不把缺失信息变成永久阻塞。
4. 用户明确要求某年某次真实考试仿真时，另按对应北京样卷核对实际模块、题量、分值和时长。样卷与定制模式有差异时说明差异；不能在普通定制卷中静默混入样卷的额外模块。

## 初中用户定制模式

适用初一至初三，跨外研、北师大、人教等已明确教材版本。默认顺序和数量为：

| 模块 | 未另指定时的教学默认 |
|---|---|
| 语法单项选择 | 10题；有充分语境，每题一个最佳答案 |
| 完形填空 | 1篇、10空；每空作为1道题 |
| 阅读理解 | A—D共4篇，每篇4题；用户要求3题时遵从 |
| 作文 | 1题，附评分标准与参考范文 |

分值和时长按教学用途合理配置并说明，不冒充官方考试配置。普通综合卷只使用这四类模块，不自动添加语篇语法填空、阅读表达、句子表达，也不将这些题塞进阅读小题或“附加练习”规避限制。“题型丰富”“参考VIP精品”本身不构成添加模块的要求；应在既定模块内丰富考点、情境和干扰项。

用户另行明确要求某专项或某次考试仿真时可采用相应题型，但须标明模式改变。这项默认不表示北京初中历史或现行官方卷没有阅读表达；不能据用户偏好推断官方事实。

## 高中独立北京模式

核心教学模块为**完形填空＋语法填空＋四篇阅读＋作文**。具体年级和考试目标确定后，按同年级、同学期、同类北京实际样本独立确定题量、分值、篇幅和写作任务。

七选五、阅读表达、听力及其他校考模块按对应北京实际样本配置；仅见分类汇编或局部预览不能证明全卷结构。不得自动套用全国卷读后续写，也不得把高一校考和北京高考固定成同一个模式。用户教学体裁偏好可以保留，真实考试仿真服从已核对的目标样卷。

通用示范可按明确的年级假设，保留用户的四篇阅读偏好，并借用下列北京笔试六模块结构作为教学训练；必须标明所做调整，不称为某校试卷复刻或该年级统一考试结构。实际校考或高考仿真仍须确定具体目标，再核对对应样卷。

### 已核实的2025北京高考笔试结构

核查日期：2026-10-03。依据[《精品解析：2025高考北京卷英语（原卷版）》公开转载](https://www.yeyulingfeng.com/wendang/415599.html)可见的卷头及1—44题，笔试为**100分、90分钟**。

| 模块 | 题量与分值 |
|---|---|
| 完形填空 | 10题×1.5分＝15分 |
| 语法填空 | A/B/C三段，10题×1.5分＝15分 |
| 阅读选择 | A/B/C/D四篇，分别3/4/3/4题，共14题×2分＝28分 |
| 七选五 | 5题×2分＝10分 |
| 阅读表达 | 4题，分别2/2/3/5分，共12分 |
| 应用文写作 | 1题，20分；该真卷要求约100词 |

分值核算：15＋15＋28＋10＋12＋20＝100。本样本没有独立语法单选或读后续写。此处仅是2025已核验结构，不能称为所有年份或所有高中校考的固定结构；指定其他年份时另行核对。

来源标题含“精品解析”，正文带学科网页脚，但本次实际读取的是第三方公开转载原卷正文，**不是学科网站内VIP全文下载或付费解析**。页面上级资源包的归档名称不能替代卷头身份；本表依据明确写有2025北京卷的卷头与题面。

### 高一校考样本与四篇训练偏好的区别

[《北京市密云区2024—2025学年高一上学期期末英语试卷（解析版）》公开转载](https://www.scribd.com/document/1060364502/精品解析-北京市密云区2024-2025学年高一上学期期末英语试卷-解析版)的可见卷头和全部模块显示：100分、90分钟；阅读选择为**A/B/C三篇、11题、22分**，另有**10分基础知识**（4道单词拼写、6道词语英译汉）。其完形15分、语法填空15分、七选五10分、阅读表达8分、作文20分，与上述北京高考分配不同。

这份资源的标题和水印虽有“精品解析/学科网”信息，实际读取渠道仍为公开转载；正文存在OCR问题，本处用来核对结构，不直接搬用OCR原句命题。不能因此声称已读VIP完整资源，也不能说“所有高一校考都为四篇阅读”。用户的四篇阅读是教学配置；严格仿真该密云样卷时应保留三篇阅读及基础知识模块。

## 出卷前的防混入检查

- 在蓝图中写明学段、具体年级、模式、四个核心模块及实际题量，区分用户配置和样卷观察。
- 初中定制卷核对是否只含语法单选、1篇完形、4篇阅读、1篇作文；不得沿用旧模板中的独立语篇填空、阅读表达或句子表达。
- 高中核对目标年级/考试场景是否明确，新增模块是否有对应北京样本依据；未读完整试卷时如实列出未核验模块。
- 检查学生卷、教师卷、任务卡、分值汇总和交付说明采用同一模式；不能只修改标题而保留旧模块。
