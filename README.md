# 北京初高中英语分层出题 Skill

面向北京英语教培的 Codex 技能：根据教材版本、年级、已教范围和学生水平编制原创练习，或将已有题目改编成 3～4 个难度递增的版本，交付学生卷与教师解析卷。

支持北师大版、人教版、外研版等教材。教材内容以教师提供的目录、词表、课文和已核对资料为准。

## 两种组卷模式

| 模式 | 默认结构 | 使用边界 |
|---|---|---|
| 初中 | 语法单项选择＋1 篇完形＋A—D 四篇阅读＋1 题作文 | 教师定制训练模式；不自动加入语篇语法填空、阅读表达、句子表达 |
| 高中 | 完形＋语法填空＋四篇阅读＋作文；其他模块按目标样卷配置 | 按具体年级及北京校考、区统考或高考目标核对，不自动套用全国卷读后续写 |

阅读篇数、小题数和分层版本数分别计算。四篇阅读不等于四个难度版本；只要求一套时不会自动生成多套。初中覆盖记叙文与说明文；高中定制训练优先采用 A/B 记叙、C 说明、D 说明或议论，真实考试仿真服从目标样卷。

初中配置是教师指定的教学要求，不代表北京所有初中考试的统一结构。完整规则见[初高中模式说明](初高中试卷模式说明.md)。

## 安装与调用

下载或克隆本仓库，将 [skills/beijing-english-exam-builder](skills/beijing-english-exam-builder) 文件夹复制到本机 `~/.codex/skills/`。如果设置了自定义 Codex 技能目录，则复制到对应目录。新开对话后调用：

```text
使用 $beijing-english-exam-builder。
对象：北京初二，外研版新修订八上。
范围：以我提供的单元目录、词表和已教语法为准。
出一套综合卷：语法单选10题、完形1篇10空、四篇阅读各4题、作文1题。
给可编辑的学生卷和教师解析卷。
```

```text
使用 $beijing-english-exam-builder。
把下面的阅读改编成3个难度递增的新版本，每篇4问。
保留核心考点，重新设计情境、证据和选项。
先检查原答案，再给学生题目、逐题解析和难度递进说明。
```

更多示例见[使用说明](英语出题Skill使用说明.md)。本仓库是供 Codex 使用的技能与示例材料，不包含独立出题应用或一键再生成脚本。Word 等文件的生成能力取决于运行环境提供的文档工具。

## 参考来源与质量要求

- 参考实际可读取的学科网北京同年级、同学期 VIP/精品资源，分别记录平台标签、访问渠道和已读范围。现有研究使用公开预览及明确标注的公开转载，没有读取受限 VIP 全文，也不将自编卷称为平台认证精品。
- 改编围绕考点、语篇证据、设问和干扰项设计，避免仅替换人名或数字；本仓库不收录付费原卷全文。
- 学生卷与教师答案分开，教师卷包含答案依据、干扰项说明、允许变体及写作评分参考。
- 难度是教学设计预估，尚未经过学生实测；教材匹配程度和来源限制在交付中说明。
